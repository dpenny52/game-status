# Product Mission

## Pitch

**GameStatus** is a server status monitoring dashboard that helps gamers check if their favorite games are online by providing a single unified view of server status across multiple popular games, eliminating the need to visit dozens of different status pages.

## Users

### Primary Customers

- **Casual Gamers:** Players who want quick visibility into whether their favorite games are playable before launching them
- **Dedicated Gamers:** Players who play multiple games and need to track maintenance schedules and outages across platforms
- **Competitive Players:** Gamers who need to know the moment servers come back online to minimize downtime

### User Personas

**Alex** (18-35)
- **Role:** Part-time gamer who plays 2-3 different online games weekly
- **Context:** Limited gaming time means every minute of downtime is frustrating
- **Pain Points:** Wastes time launching games only to find servers are down; doesn't know where to check status for each game
- **Goals:** Quickly see if favorite games are online before starting a gaming session

**Jordan** (16-28)
- **Role:** Dedicated MMO and competitive game player
- **Context:** Plays games with regular maintenance windows (WoW, FFXIV) and wants to jump back in immediately when servers return
- **Pain Points:** Constantly refreshing multiple status pages during maintenance; missing the moment servers come back online
- **Goals:** Get notified instantly when a game's servers are back up so they can be first in queue

## The Problem

### Fragmented Server Status Information

Gamers currently must visit separate websites, Twitter accounts, or launcher apps to check if each game's servers are online. During major outages or maintenance windows, players waste significant time checking multiple sources and may miss when services are restored.

**Our Solution:** A single dashboard that aggregates server status from all major games, with optional email alerts for when specific games come back online.

## Differentiators

### Unified Multi-Game Dashboard
Unlike checking individual game launchers, official status pages, or Twitter accounts, we provide a single view of all major game server statuses in one place. This saves gamers from bookmarking and checking 10+ different sources.

### Proactive Notifications
Unlike passive status pages that require manual refreshing, we offer email alerts that notify users the moment their chosen game's servers come back online. This means users can do other things instead of constantly refreshing.

### Personalized Experience
Unlike generic status pages, users can save their favorite games to always appear at the top of their dashboard, creating a personalized view tailored to the games they actually play.

## Key Features

### Core Features

- **Multi-Game Status Dashboard:** View server status for World of Warcraft, Diablo, Overwatch, Steam, League of Legends, Valorant, Fortnite, Minecraft, and Final Fantasy XIV all in one place
- **Real-Time Status Updates:** See current server status with automatic refresh to stay up-to-date without manual page reloads

### Personalization Features

- **Favorites List:** Save preferred games to a favorites list that pins them to the top of the dashboard for quick access
- **Custom Alerts:** Set up email notifications for specific games to be alerted when servers come back online

### Platform Coverage

- **Blizzard Games:** World of Warcraft, Diablo IV, Overwatch 2, Hearthstone, and other Battle.net titles
- **Riot Games:** League of Legends, Valorant, Teamfight Tactics, and other Riot titles
- **Steam Platform:** Steam store and community server status
- **Epic Games:** Fortnite server status
- **Mojang/Microsoft:** Minecraft server status
- **Square Enix:** Final Fantasy XIV server status
