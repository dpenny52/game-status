# Game Status

A unified server status monitoring dashboard for gamers. Check if your favorite games are online from a single view instead of visiting dozens of different status pages.

## About

GameStatus aggregates server status from popular games including:
- Blizzard titles (World of Warcraft, Diablo IV, Overwatch 2)
- Riot Games (League of Legends, Valorant)
- Steam, Fortnite, Minecraft, Final Fantasy XIV, and more

Features include real-time status updates, a favorites system, and email alerts for when servers come back online.

## Purpose

This project is being developed to test the [Agent OS](https://github.com/buildermethods/agent-os) tool for AI-assisted software development workflows.
